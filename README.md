# Machine learning suite for basic convolutional networks 
This C++ machine learning suite originally developed for a Master Thesis can be used to train convolutional and dense networks, on CPU and GPU. 

# Dependencies

- intel mkl_dnn v0.14
  https://github.com/uxlfoundation/oneDNN/releases/tag/v0.14
- cudnn 7.6, cuda 10.2 
- openmp 
- openblas
